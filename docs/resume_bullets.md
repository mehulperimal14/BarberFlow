# Resume Bullet Points: BarberFlow

Add these impact-oriented bullets to your resume to showcase this project.

---

### Option 1 (Data Analyst / Business Analyst focused)
* **Analyzed** barber shop capacity utilization and customer queuing dynamics using SQL and Python, identifying key operational bottlenecks where wait times over 25 minutes resulted in a 40% drop in customer satisfaction ratings.
* **Designed and developed** a responsive React/Vite dashboard featuring interactive visualizations (Recharts) to track market-wide KPIs, customer demographic no-show rates, and spatial capacity opportunity indices.

### Option 2 (Analytics Engineer focused)
* **Built** a normalized relational database in SQLite with full foreign key constraints and indexes to store simulated queuing states, dimensioning 50 shops, 5,000 customers, and 60,000+ customer visits.
* **Developed** an API layer in FastAPI executing raw SQL queries (CTEs, joins, aggregations) to power real-time dashboards and feed feature vectors into machine learning models.

### Option 3 (Data Scientist / ML Analyst focused)
* **Trained and deployed** Random Forest Regressor models using Scikit-learn to forecast hourly customer demand ($R^2 = 0.81$) and estimate walk-in waiting times, using time-based train-test splits to prevent data leakage.
* **Implemented** a transparent weighted recommendation system combining geographic distance, ratings, prices, and live queue wait times to match customer demand with shop capacity.
